# Changelog

## 0.1.0 - Preview

- Local macOS dashboard with project status, attention details, and project actions.
- Reusable imports, local exports, history, and explicit Codex outcome sync.
- Project launch controls and approval-based suggestions.
- User-installed Skills registry with evidence-linked project usage.
- Dark mode, collapsible navigation, accessible chart totals, and page-heading focus.
- Empty first-run registry; personal data is excluded from release packages.
- Sidebar feedback links for GitHub bug reports and feature requests, without attached user data.

Initial downloads are unsigned. Apple Silicon is the locally verified target.
